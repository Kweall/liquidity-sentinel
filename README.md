# Liquidity Sentinel — система раннего предупреждения стресса ликвидности

**Liquidity Sentinel** — это программный комплекс для автоматического сбора, анализа и предиктивной аналитики финансовой стабильности российского рублёвого денежного рынка. Система объединяет данные из открытых источников (ЦБ РФ, Минфин, Росказна, Мосбиржа, ФНС) и с помощью методов машинного обучения формирует единый опережающий индикатор — **Liquidity Stress Index (LSI)**, который в реальном времени оценивает уровень стресса ликвидности в банковской системе.

Проект разработан в рамках практики студентами МАИ (кафедра 806) по техническому заданию ПАО «Промсвязьбанк». Система полностью автоматизирована, масштабируема и включает в себя дашборд для визуализации и интерактивный чат-ассистент на основе LLM.

---

## Цели и задачи

- **Раннее обнаружение стресса ликвидности** — выявление предвестников дефицита ликвидности за 1–2 дня до его наступления.
- **Автоматический сбор данных** из пяти независимых источников с периодичностью не реже одного раза в день.
- **Агрегация сигналов** в единый интерпретируемый индекс LSI (0–100) с возможностью разложения по модулям.
- **Визуализация и оповещение** — дашборд с графиками, цветовой индикацией и алертами.
- **Интерактивный анализ** — текстовые комментарии (LLM) и RAG‑чат для ответов на вопросы об исторических данных.

---

## Архитектура системы

Система состоит из пяти независимых расчётных модулей (M1–M5), агрегационного слоя LSI и LLM‑модуля. Все модули реализованы на Python и используют общие утилиты для нормализации (MAD) и валидации.

### Модули

| Модуль | Экономическая роль | Источник данных | Частота |
|--------|-------------------|----------------|---------|
| **M1** | Усреднение обязательных резервов | ЦБ РФ (Excel) | Ежемесячно |
| **M2** | Аукционы РЕПО ЦБ | ЦБ РФ (SOAP‑сервис) | Ежедневно |
| **M3** | Размещение ОФЗ | Минфин (Excel), Мосбиржа (кривая) | 2 раза в неделю |
| **M4** | Налоговый период и сезонность | ФНС (XML открытые данные) | Детерминировано |
| **M5** | Средства федерального казначейства | ЦБ РФ, Росказна (docx) | Ежемесячно |

**Агрегационный слой LSI**  
Принимает нормализованные сигналы всех модулей, применяет взвешенную сумму и сигмоидную трансформацию, учитывает сезонный множитель из M4. Результат — LSI (0–100) и цветовая зона («зелёный», «жёлтый», «красный»).

**LLM‑модуль**  
- **Автоматический комментарий** — генерируется при каждом пересчёте LSI на основе текущих значений и ближайших событий.  
- **RAG‑чат** — отдельная страница дашборда, где пользователь может задать вопрос на естественном языке, и система ответит, используя исторические данные (локальная модель Qwen2.5 через Ollama).

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/PaVGris/liquidity-sentinel.git
cd liquidity-sentinel
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Дополнительные инструменты

- **Ollama** (для LLM-модуля) — [скачайте](https://ollama.com/download) и запустите сервер:
  ```bash
  ollama serve
  ollama pull qwen2.5:3b
  ```
- **Playwright** (для парсинга Минфина):
  ```bash
  playwright install chromium
  ```

### 5. Первичный запуск (автоматическая подготовка данных)

При первом запуске любого модуля система автоматически загрузит необходимые файлы.

Затем запустите агрегатор:

```bash
python -m modules.lsi_aggregator
```

Агрегатор автоматически вызовет все модули, если их выходные файлы отсутствуют.

### 6. Запуск дашборда

```bash
streamlit run dashboard/app.py
```

Откройте браузер по адресу `http://localhost:8501`. В боковом меню доступны страницы:
- **Главная** — график LSI, метрики, алерты.
- **Аналитик** — RAG-чат для вопросов о ликвидности.

## Результаты

### Liquidity Stress Index (LSI)

LSI рассчитывается по формуле:

```
lsi_raw = (w1*signal_m1 + w2*signal_m2 + w3*signal_m3 + w5*signal_m5) * Seasonal_Factor
lsi = 100 / (1 + exp(-k * (lsi_raw - 0.4))), где k=10
```

Веса:
- M2 (РЕПО) – 0.35
- M5 (казначейство) – 0.30
- M1 (резервы) – 0.20
- M3 (ОФЗ) – 0.15
- M4 – 0.00 (участвует только через множитель)

**Интерпретация**:
- **0–40** — зелёная зона, ликвидность в норме.
- **40–70** — жёлтая зона, повышенное напряжение, требуется мониторинг.
- **70–100** — красная зона, активный стресс, необходимо вмешательство.

### LLM-комментарий (пример)

> *«Текущий уровень ликвидности находится в норме (LSI 7.6, зелёная зона). Основное давление создают аукционы РЕПО ЦБ (M2), демонстрирующие повышенный спрос. В ближайшие дни ожидается налоговая неделя (25.06.2026), что может временно усилить дефицит ликвидности, однако аукционы ОФЗ 28.06.2026 могут предоставить дополнительное фондирование.»*
